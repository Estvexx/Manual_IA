Este guia distingue o que está nos materiais do projeto do que falta testar. Não avance sobre etapas pendentes. O arranque do manual não instala LocalGPT.

PASSO 01

O que é

O código encontrado corresponde ao projeto PromtEngineer/localGPT, identificado pelos seus ficheiros de documentação. Usa uma interface web, serviços de processamento de documentos e Ollama para os modelos de conversa.

Um índice é uma organização pesquisável do conteúdo dos documentos. Criá-lo permite procurar excertos antes de gerar uma resposta.

Projeto identificado, versão ainda por fixar

A cópia disponível tem alterações locais. Clonar a versão atual do projeto público não garante obter essas alterações.

PASSO 02

Requisitos específicos

  • Windows 11, Git, WSL 2 e Docker Desktop preparados segundo o README.
  • Cópia aprovada do LocalGPT, incluindo os ficheiros Docker e a configuração correspondente.
  • Ollama local acessível aos contentores; internet para descarregar imagens, dependências e modelos.
  • Portas livres previstas pelo Compose encontrado: 3000 (interface), 8000 e 8001 (serviços).
Por completar com a configuração testada

Confirmar RAM, CPU/GPU e espaço necessários para os modelos finais. O exemplo relata limitações num computador com 16 GB de RAM; isso não estabelece um requisito mínimo. A porta 8001 também aparece na receita PrivateGPT: não iniciar ambas com essa configuração.

PASSO 03

Instalação

  1. Conclua a preparação do Windows descrita no README deste manual.
  2. Obtenha do responsável a cópia ou o commit que inclui as correções locais.
  3. Instale Ollama para Windows segundo a documentação oficial; o instalador funciona na conta do utilizador. Reabra o PowerShell depois de instalar.
  4. Aguarde pela configuração final dos modelos e da ligação ao Ollama antes de construir os serviços.
Por completar com a configuração testada

Faltam a revisão exata do código e o procedimento Windows testado para a ligação entre os contentores e Ollama. O manual não replica o script de instalação Linux apresentado na documentação de referência.

PASSO 04

Configuração do modelo

Por completar com a configuração testada

Fornecer o ficheiro de configuração efetivamente utilizado, sem segredos, os modelos escolhidos e o procedimento de download. Confirmar que geração, enriquecimento, embeddings e reordenação são locais, sem alternativa remota ativada. Validar também os componentes de conversão de documentos necessários para trabalhar sem internet.

PASSO 05

Arranque e acesso

Depois de o responsável concluir os passos anteriores, a documentação desta cópia prevê o comando abaixo. Não é um passo de instalação validado nesta entrega.

Onde: PowerShell normal, na raiz da cópia aprovada do LocalGPT, onde existem docker-compose.yml e docker.env. Administrador: não.

docker compose --env-file docker.env up --build -d

Resultado esperado: construção das imagens e arranque de rag-api, backend e frontend, se a configuração e os modelos estiverem corretos.

Downloads e espera

O primeiro arranque pode descarregar modelos. O Compose atual concede 900 segundos de tolerância inicial ao serviço de documentos; isso não é uma previsão do tempo total. A primeira pergunta pode ainda carregar o modelo de reordenação.

Onde: PowerShell normal, na mesma pasta do LocalGPT. Administrador: não.

docker compose --env-file docker.env ps

Resultado esperado: serviços listados; aguarde pelos estados saudáveis antes de abrir a interface.

O endereço previsto no ficheiro é http://localhost:3000. Só fica disponível depois do arranque da aplicação; não é o endereço do manual.

PASSO 06

Carregamento de documentos

Na interface identificada no código:

  1. Escolha Create new index (criar novo índice).
  2. Em Index name, escreva um nome novo que reconheça.
  3. Escolha um documento pequeno de teste. O seletor permite PDF, DOCX, DOC, HTML, Markdown e TXT; isto não garante que todos os documentos sejam convertidos com sucesso.
  4. Mantenha apenas os modelos locais aprovados e escolha Start indexing (iniciar indexação).
  5. Aguarde pelo fim da indexação antes de fazer perguntas. Uma digitalização pode exigir reconhecimento de texto adicional.
Por completar com a configuração testada

Confirmar os modelos apresentados na interface e a indexação bem-sucedida num documento de exemplo. Não carregue XLSX diretamente: esse formato não consta do seletor inspecionado.

PASSO 07

Primeira pergunta

Quando o índice estiver pronto, abra a conversa associada ao índice e escreva:

Resume os pontos principais deste documento em três frases e indica os excertos que sustentam a resposta. Se a informação não estiver no documento, diz que não a encontraste.

Compare a resposta com o documento original. Uma resposta bem escrita pode conter erros; confirme os excertos e valores.

Por completar com a configuração testada

Registar o documento de teste, a associação do índice à conversa e uma resposta conferida no original.

PASSO 08

Parar e voltar a iniciar

Os comandos seguintes destinam-se à instalação feita com o Compose e o ficheiro docker.env indicados acima.

Onde: PowerShell normal, na pasta do LocalGPT, não na pasta manual. Administrador: não.

docker compose --env-file docker.env stop

Resultado esperado: os serviços LocalGPT param. Os volumes e documentos não são removidos.

Noutro dia, abra Docker Desktop e Ollama e aguarde pelo arranque de ambos.

Onde: PowerShell normal, na mesma pasta do LocalGPT. Administrador: não.

docker compose --env-file docker.env up -d

Resultado esperado: os serviços são iniciados novamente; aguarde que fiquem saudáveis e abra localhost:3000.

O Compose atual guarda SQLite num volume próprio e usa pastas para índices e documentos. Não elimine esses dados. Parar o LocalGPT não fecha o Ollama instalado no Windows.

PASSO 09

Problemas frequentes

A interface demora a abrir

O backend espera que o serviço de documentos esteja saudável. Aguarde pelos downloads e consulte os registos; não existe uma duração garantida.

Nome de índice repetido

Escolha outro nome. As notas de correção distinguem este conflito de um bloqueio da base de dados.

Porta ocupada ou modelo indisponível

Confirme se o PrivateGPT está a usar a porta 8001. Para modelos, confirme a configuração aprovada e a ligação ao Ollama; não troque para um serviço externo.

Onde: PowerShell normal, na pasta do LocalGPT. Administrador: não.

docker compose --env-file docker.env logs --tail 50 rag-api

Resultado esperado: últimas mensagens do serviço de documentos; partilhe o erro com o responsável, retirando informação privada.

Se houver erro de memória ou de base de dados, pare a operação e preserve os volumes. As correções existentes precisam de um teste completo na versão entregue.
